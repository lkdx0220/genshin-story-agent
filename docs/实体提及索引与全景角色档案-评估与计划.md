# 实体提及索引与全景角色档案：评估与实施计划

> 目标：把 C4 类“全景梳理 + 所有角色评价”题的证据覆盖率，从当前 8 个主要角色提升到 25~30 个角色/组织/圣遗物，逼近 WorkBuddy 的考据深度。
> 性质：本地确定性索引 + 代码旁路，不引入模型判断、不改变普通题路径。

---

## 1. 问题定位（已实测）

当前全景全文旁路已经读入了：

```text
4 条任务全文 + 8 张地图文本全文 = 约 71,000 字
```

但 C4 答案仍只有 2663 字、8 个角色，原因是：

1. **图里缺“实体提及索引”**：
   - 图只有显式 `data-entry-id` 链接；
   - 不知道“任务全文里提到了伊兹梅洛/拉莉莎/圣遗物/组织”；
   - 无法按人名反向加载相关词条。
2. **全景证据组装没走角色轴**：
   - 代码只加载任务+地图文本；
   - 没有“抽人名 → 批量加载角色/圣遗物/组织词条”这一跳。
3. **Answer 输出被压缩**：
   - 拿到了 71k 证据，只输出 2.6k 概要；
   - 需要输出规约强制“逐线 + 逐角色 + 逐地图文本”。

## 3. 方案设计

### 3.1 实体字典

来源：

```text
graph 节点的 title + aliases
类型限制：
  character / npc / organization / weapon / artifact
  book / monster / region_feature / character_anecdote
  task / activity（用于跨任务提及）
```

过滤规则：

```text
- 长度 1 的字不建索引（避免“影/琴/空”误命中）
- 复用 character_aliases 已有的歧义别名跳过规则
- 同名字不同 ID 时，按类型优先级：character > npc > organization > ...
- 名称仅出现在“非叙事类型”词条时不作为实体索引
```

### 3.2 实体提及索引

数据结构：

```json
{
  "version": 1,
  "built_at": "...",
  "entities": {
    "<entity_id>": {
      "name": "伊兹梅洛",
      "type": "npc",
      "mentions": [
        {"entry_id": "509591", "count": 4, "first_offset": 1234},
        ...
      ]
    }
  },
  "inverted": {
    "<entry_id>": ["entity_id1", "entity_id2", ...]
  }
}
```

构建方式：

```text
for source_entry in graph.entries:
    text = title + "\n" + full_text
    用多模式匹配（Aho-Corasick / 纯 Python 前缀树）扫描全部实体名
    -> 生成 entity -> source_entry 的反向边
```

- **不新增外部依赖**：用纯 Python Aho-Corasick 或按首字符分桶扫描；
- 索引文件：`kb_vectors/wiki_entity_mention_index.json`（gitignore）；
- 增量更新：与现有 `--check/--apply` 联动，changed_ids 只重建受影响节点。

### 3.3 全景角色档案展开（代码旁路）

在现有 `_maybe_auto_full_text_panoramic()` 基础上扩展：

```text
1. 读入任务全文 + 地图文本全文（现有逻辑）
2. 用实体提及索引查：这些全文里出现了哪些实体
3. 按类型优先级和提及次数排序
4. 取 top 25~30 个实体
5. 加载这些实体的 graph 词条全文
6. 追加进全景证据 ToolMessage
```

证据预算：

```text
任务全文：约 67,000 字
地图文本：约 8,000 字
实体档案：top 30 × 平均 1,500 字 ≈ 45,000 字
合计：约 120,000 字
```

qwen3.7-max 可以承载，但必须配合“分块读取/顺序使用”的输出规约，防止模型又压缩。

### 3.4 输出规约

全景题注入系统提示：

```text
必须按以下结构输出，不得压缩成概要：
1. 每条任务线：触发、流程、关键对话、结局
2. 每个相关角色：独立小节，写明直接证据与评价
3. 每张相关地图文本：单独引用原文并解读
4. 目标篇幅 8,000~15,000 字
5. 不确定的事实标注“证据未覆盖”，不得用文学化表述掩盖
```

---

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 实体名误命中（短名/人名出现在无关词条） | 长度过滤 + 类型优先级 + 只取叙事类 source |
| 索引体积/构建时间 | 先测；预计 10~50MB，分钟级 |
| 角色档案把上下文撑爆 | top 30 + 单实体截断 + 全景题才启用 |
| 普通题被误伤 | 只在全景题旁路内启用，普通题完全不加载索引 |
| 增量不同步 | 更新图时同步重建索引；或与 manifest 联动 |
| 模型输出仍过短 | 输出规约 + 覆盖率检查（角色小节数 < 期望时重生成一次） |
