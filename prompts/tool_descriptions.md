# 原神剧情助手 - 工具函数说明

## query_character
查询原神角色详细信息。
- 参数 `name`: 角色名称（如"胡桃"、"钟离"、"雷电将军"）
- 返回: 角色基本信息、神之眼、武器类型、所属、命之座、简介、角色故事（含角色详细、角色故事1-5、神之眼故事）、相关剧情

## query_region
查询原神地区（国家）信息。
- 参数 `name`: 地区名称（如"蒙德"、"璃月"、"稻妻"、"须弥"、"枫丹"）
- 返回: 地区元素、神明、理念、剧情章节、主要地点、简介

## query_story
查询版本主线剧情信息。
- 参数 `arc_name`: 章节名称关键词（如"辞行久远之躯"、"千手百眼"、"虚空鼓动"）
- 返回: 章节名称、所属地区、主要角色、剧情概要、关键事件

## query_weapon
查询武器信息。
- 参数 `name`: 武器名称（如"护摩之杖"、"雾切之回光"）
- 返回: 武器稀有度、类型、副属性、技能名称、实装版本、简介

## query_quest
查询传说任务/世界任务信息。
- 参数 `name`: 任务名称或角色名（如"引蝶之章"、"胡桃"、"钟离传说任务"）
- 返回: 任务名称、类型、关联角色、简介

## list_characters_by_element
按元素类型列出所有角色。
- 参数 `element`: 元素类型（火/水/风/雷/冰/岩/草）
- 返回: 该元素所有角色的名称、称号、武器类型、所属

## list_characters_by_region
按所属地区列出所有角色。
- 参数 `region`: 地区名称（蒙德/璃月/稻妻/须弥/枫丹/纳塔/至冬/其他）
- 返回: 该地区所有角色的名称、称号、元素、武器类型、稀有度

## list_characters_by_weapon
按武器类型列出所有角色。
- 参数 `weapon_type`: 武器类型（单手剑/双手剑/长柄武器/法器/弓）
- 返回: 该武器类型所有角色的名称、称号、元素、所属、稀有度

## list_characters_by_rarity
按稀有度列出所有角色。
- 参数 `rarity`: 稀有度（4或5）
- 返回: 该稀有度所有角色的名称、称号、元素、武器类型、所属

## search_all
全局搜索原神知识库，在角色、地区、剧情、武器、任务、圣遗物中模糊匹配。
- 参数 `query`: 搜索关键词
- 返回: 所有匹配的条目

## load_book_content
加载指定书籍的完整文本。
- 参数 `book_name`: 书籍名称（如"白夜国馆藏"、"火山大王与缝影针"）
- 返回: 书籍全文（前3000字预览 + 总字数提示）

## load_quest_content
加载指定任务的剧情内容。短任务（<=9000字）返回全文；长任务智能路由：
- 参数 `quest_name`: 任务名称片段（如"捕风"、"不动鸣神"、"狮之血"）
- 参数 `query`: 用户的具体问题或关键词（可选）。传入后在长任务中通过BM25检索相关原文片段（轨道B）；不传入则返回离线生成的剧情大纲（轨道A）

## count_character_lines
统计指定角色在剧情任务中说了多少句话。自动识别角色的别名。
- 参数 `character_name`: 角色名称（可以是真名、代号或别名，如"哥伦比娅"会自动匹配"少女"）
- 参数 `quest_name`: 任务名称关键词（可选，为空则搜索所有任务）
- 返回: 按任务分组的台词计数 + 样本台词 + 总计

## query_monster
查询怪物图鉴：属性、抗性、掉落、技能等。
- 参数 `name`: 怪物名称（模糊匹配）
- 返回: 怪物类型、元素属性、攻击属性、8种元素抗性、掉落材料、出现地点、技能名称和说明

## query_artifact
查询圣遗物套装：两件套/四件套效果、部位故事。
- 参数 `name`: 套装名称（模糊匹配，如"绝缘之旗印"、"沉沦之心"）
- 返回: 稀有度、两件套效果、四件套效果、5个部位故事（生之花/死之羽/时之沙/空之杯/理之冠）

## query_material
查询材料：用途、来源、类型等。
- 参数 `name`: 材料名称（模糊匹配）
- 返回: 材料类型、稀有度、用途、来源、简介

## query_collectible
查询采集物/地区特产：分布地区、刷新时间、用途。
- 参数 `name`: 采集物名称（模糊匹配）
- 返回: 类型、分布地区、刷新时间、用途

## query_recipe
查询食谱：效果、材料、获取方式。
- 参数 `name`: 食谱名称（模糊匹配）
- 返回: 稀有度、效果、所需材料、获取方式

## query_concept
查询游戏概念/组织/设定信息：如教令院、七星、神之眼、坎瑞亚等。
- 参数 `name`: 概念名称（模糊匹配）
- 返回: 类型、表格数据（如果有）、章节内容、正文预览

## query_food
查询食物/料理信息：名称、效果、介绍、所需食材、获取方式。
- 参数 `name`: 食物名称（模糊匹配）
- 返回: 稀有度、类型、类别、效果说明、介绍、所需食材、获取方式、特殊料理角色
